# Объединение XML-файлов

Веб-приложение на HTML/CSS/JavaScript для объединения нескольких XML-файлов с элементами `<problem>` в один `<problems>…</problems>`.

## Использование

1. Откройте `xml-merger/index.html` или страницу GitHub Pages `/XML_to_Gift/xml-merger/`.
2. Выберите один или несколько `.xml`.
3. Нажмите **Объединить**.
4. При необходимости нажмите **Форматировать** (удаляет атрибуты `markdown`, `max_attempts`, `showanswer`, `display_name`).
5. Нажмите **Скачать** для сохранения текущего содержимого поля в `merged.xml`.
6. Перейдите по ссылке **в XML → GIFT** для последующего преобразования.

Работает локально в браузере, файлы не отправляются на сервер.

**Примечание:** кнопка объединения обновляет `display_name` на каждом `<problem>` по порядку; кнопка форматирования эти атрибуты удаляет. Если в одном `<problem>` несколько вопросов, имена задаются на уровне блока, а не каждого вопроса.

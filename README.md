# XML → GIFT конвертер

Веб-конвертер XML в формат GIFT для импорта вопросов в Moodle. Работает локально в браузере, без сервера и отправки XML в интернет.

## Возможности

- одиночный и множественный выбор;
- короткий ответ, числовой ответ, «да/нет»;
- несколько вопросов внутри одного `<problem>`;
- автоматическое распределение веса верных вариантов до 100% (в пределах пяти десятичных знаков);
- загрузка `.xml` и скачивание `.gift`.

## Запуск

Откройте `index.html` в браузере. Для публикации через GitHub Pages: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save. После публикации откройте адрес, который покажет GitHub Pages.

## Исходный интерфейс

[CodePen](https://codepen.io/mikhail21990/pen/WbbQvZK). В данном проекте используется доработанный конвертер на основе предоставленных пользователем HTML/CSS/JS.

## Примечание

Проверяйте полученные GIFT-файлы при импорте в Moodle, особенно правила штрафов для неправильных ответов (в текущей логике: -100%).

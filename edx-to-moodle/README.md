# EDX GIFT → Moodle GIFT

Веб-конвертер вопросов для проверочных и контрольных работ. Работает локально в браузере без передачи данных на сервер.

## Использование

1. Вставьте пронумерованные вопросы.
2. Нажмите «Конвертировать».
3. Проверьте результат и нажмите «Скачать» для сохранения файла `.gift`.

Поддерживаются одиночный выбор `(x)`/`( )`, множественный `[x]`/`[ ]`, короткий ответ `=` или `or=`, числовой ответ `#42` / `#3.14:0.01`.

Пример:

```text
1. Выберите два цвета
[x] Синий
[x] Красный
[ ] Автобус
2. Сколько будет 2 + 2?
#4
```

В множественном выборе доли положительных ответов суммируются ровно до 100% (при округлении до пяти знаков после запятой). Неверные ответы имеют штраф -100%, как и в исходном скрипте. Проверьте нужную политику штрафов в Moodle.

Частичная поддержка Cloze: `[[вариант,(правильный),другой]]` преобразуется в поле `{1:MULTICHOICE:...}`. Cloze-вопросы нужно **отделять от обычных вопросов** и импортировать через формат «Вложенные ответы (Cloze)». Matching-тип не поддерживается: вместо некорректного экспорта будет показана ошибка.

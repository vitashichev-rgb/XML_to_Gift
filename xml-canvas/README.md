# XML Canvas → GIFT

Конвертер XML-вопросов, расположенных последовательно внутри одного `<problem>`.

## Возможности
- Одиночный выбор (`multiplechoiceresponse`)
- Множественный выбор (`choiceresponse` или несколько правильных ответов в `multiplechoiceresponse`)
- Короткие ответы (`stringresponse`)
- Числовые ответы (`numericalresponse`)
- Частичная поддержка Cloze (`optionresponse`): при обнаружении отображается предупреждение. Если в XML присутствует **ровно один Cloze и нет обычных вопросов**, он выводится в поле результата. Если в файле смешаны типы, Cloze не включаются в общий GIFT-файл. Для каждого Cloze рекомендуется отдельный исходный XML и отдельный выходной `.gift` с импортом как Cloze.

Баллы правильных вариантов в множественном выборе в сумме составляют 100% (точность до 5 знаков после запятой). Неправильный вариант получает -100% (проверьте правила оценивания в Moodle).

Использование: поместите папку `xml-canvas` в корень репозитория рядом с `xml-merger` и `edx-to-moodle`. Открывайте `https://vitashichev-rgb.github.io/XML_to_Gift/xml-canvas/index.html`.

Работает локально в браузере без сервера.
